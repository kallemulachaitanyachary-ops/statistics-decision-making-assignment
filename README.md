# Statistics for Decision Making Assignment

This project contains statistical analysis performed on Australian real estate data using Python and Jupyter Notebook.

## Topics Covered
- One-Sample T-Test
- Independent Two-Sample T-Test
- Binomial Probability
- Two-Way ANOVA
- Hypothesis Testing
- p-value Interpretation

## Tools Used
- Python
- Pandas
- NumPy
- SciPy
- Statsmodels
- Jupyter Notebook
